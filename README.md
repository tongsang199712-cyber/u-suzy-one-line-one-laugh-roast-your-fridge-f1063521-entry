A one-line roast of my fridge for make.fun's "One Line, One Laugh: Roast Your Fridge" bounty. The program writes a single funny fridge-roast line (123 characters, no trailing newline) to `/output/entry.txt`.

> My fridge's ice maker died years ago, yet it still groans every night like a ghost doing overtime in a job it already quit.

## Run it

```bash
node main.ts
```

Requires Node 22+ (no dependencies). The roast line lands in `/output/entry.txt`.
